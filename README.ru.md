# BudgetOS — бюджет из заметок

[English](README.md) · Русский

Локальный бюджет для тех, кто уже записывает расходы обычным текстом.
Вставьте привычный список вместо повторного ввода категорий. Сравнивайте план и факт, а подробные записи добавляйте при необходимости.
Приложение состоит из статических HTML, CSS и JavaScript. Подключения к банку и аккаунта нет.

## Запуск

```sh
python3 -m http.server 8000
```

Откройте `http://localhost:8000`. Для установки на телефон и работы без сети разместите файлы через HTTPS, например на GitHub Pages.
Суммы отображаются в BYN. Стартовые категории и числа — искусственные примеры.

## Пример импорта

```text
Траты (январь) 2026
100 (35) продукты
40 (10) транспорт
```

Нажмите **Импорт**, вставьте текст и выберите **Импортировать**.
Парсер понимает план, факт, название категории и поддерживаемые служебные строки с доходами и расходами.
Проверьте получившиеся категории после импорта. Отдельного предварительного просмотра перед применением пока нет.

## Возможности и границы

- Категории по месяцам, план, факт и остаток бюджета.
- Необязательные отдельные записи расходов и компактное сравнение категорий.
- Данные в браузере и экспорт JSON. Банковской интеграции и синхронизации нет.
- Стартовый месяц — декабрь 2025 года. Другой месяц можно импортировать.

Кнопка «Экспорт» копирует JSON в буфер обмена. Сохраните этот текст самостоятельно. Интерфейса восстановления JSON пока нет.
Для выбора месяца используйте заголовок `Траты (январь) 2026`. Без распознанного заголовка импорт изменяет выбранный месяц.
Очистка данных сайта удаляет бюджет. Google Fonts могут быть недоступны без сети; остаются системные шрифты.
